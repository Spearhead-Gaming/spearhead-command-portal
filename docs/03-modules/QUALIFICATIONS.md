# Qualifications Module

## Purpose

Track member qualifications clearly and make readiness easy to understand.

## Core Features

- Qualification catalog
- Categories
- Member qualification records
- Instructor sign-off
- Expiration dates
- Qualification matrix
- Required qualifications by unit/position
- Unit requirement timelines

## Qualification Matrix

A grid view showing members against qualifications.

Example columns:
- Rifleman
- CLS
- RTO
- Airborne
- Ranger
- Pilot
- Zeus
- Mission Maker

## Rules

- Only authorized users can award qualifications
- Revoked qualifications should be logged
- Expired qualifications should be visible
- Readiness requirements are unit-scoped.
- Some units may have no required qualifications.
- Unit requirements may define a completion timeline.
