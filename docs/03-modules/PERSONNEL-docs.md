# Personnel Module

## Purpose

Manage official member records.

## Core Features

- Member profiles
- Rank tracking
- Unit assignment
- Position assignment
- Profile status
- Notes
- Logs
- Service history

## Member Profile Fields

- Display name
- Discord ID
- Steam ID / Arma ID
- Rank
- Unit
- Position
- Status
- Join date
- Qualifications
- Awards
- Attendance summary
- Service timeline

## Profile Logs

Automatically record important changes:
- rank changes
- unit transfers
- qualification awards
- status changes
- position changes
