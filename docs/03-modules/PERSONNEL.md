# Personnel Module

## Purpose

Manage official member records.

## Core Features

- Member profiles
- Optional rank tracking
- Unit assignment
- Position assignment
- Profile status
- Notes
- Logs
- Service history

## Member Profile Fields

- Discord display name as the primary visible member name
- Discord ID
- Steam ID / Arma ID
- Rank, optional
- Unit
- Position
- Status
- Join date
- Qualifications
- Awards
- Attendance summary
- Service timeline

## Profile Logs

Automatically record important changes:
- rank changes
- unit transfers
- qualification awards
- status changes
- position changes
