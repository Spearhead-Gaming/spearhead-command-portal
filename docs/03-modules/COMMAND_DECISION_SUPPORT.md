# Command Decision Support Module

## Purpose

Command Decision Support presents explainable recommendations to command staff.

It helps answer:

- What is happening?
- What needs attention?
- What should command consider doing next?

## Scope

Included:

- recommendation generation from rule evidence
- persistent recommendation history
- dismiss and resolve lifecycle actions
- commander dashboard recommendations
- commander's intent assessment records

Not included:

- AI-generated decisions
- automatic approvals
- automatic operation branch selection
- automatic roster, attendance, or publishing changes

## Initial Data Sources

- Operational Health
- Operational Readiness
- Publication Readiness
- Patrol and Patrol AAR rules
- Attendance and RSVP health signals
- Deployment resource readiness

## UI Surfaces

- Commander Dashboard
- Operations Package recommendation queue
- Recommendation history inspector
- Commander's Intent Assessment panel
