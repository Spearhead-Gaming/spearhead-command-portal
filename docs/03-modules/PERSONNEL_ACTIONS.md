# Personnel Actions

## Purpose

Personnel Actions are lightweight follow-up records for S1, unit leadership, training staff, or command attention.

## Examples

- Assignment change
- Status change
- LOA return
- Qualification exception
- Profile correction
- Separation or reactivation review placeholder

## Rules

- Use Personnel Actions for tracking work.
- Use the Universal Case Engine when a review, decision, confidentiality policy, or appeal path is needed.
- Do not use Personnel Actions as proof of wrongdoing.
- Audit meaningful creates, updates, and resolutions.

## Permissions

- `personnel.actions.view`
- `personnel.actions.manage`
