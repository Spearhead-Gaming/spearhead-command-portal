# Attendance Module

## Purpose

Track attendance for operations and training.

## Attendance Statuses

- Present
- Absent
- Excused
- Late
- LOA

## Core Features

- RSVP before event
- Attendance record after event
- Staff override
- Unit attendance summaries
- Member attendance history

## Spearhead Rules

- Attendance is unit-scoped for readiness and leadership reporting.
- Community attendance is an aggregate metric only.
- Member attendance should be interpreted in the context of the assigned unit.

## Discord Behavior

Members should be able to RSVP from Discord.
