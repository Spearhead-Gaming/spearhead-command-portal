# Campaigns Module

## Purpose

Group related operations into a readable campaign experience.

## Campaign Page

Each campaign should show:
- Title
- Status
- Current phase
- Overview
- Story/background
- Participating units
- Timeline
- Upcoming operation
- Completed operations
- CONOP links
- AAR links
- Attendance statistics
- Media

## Campaign Statuses

- Planning
- Active
- Paused
- Completed
- Archived

## Goal

Campaign pages should be easy for members to read and useful for S3 to manage.
