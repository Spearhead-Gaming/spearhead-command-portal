# Notifications Module

## Purpose

Route important system messages to the correct people.

For staff-facing communication management, see [COMMUNICATIONS_CENTER.md](COMMUNICATIONS_CENTER.md).

## Notification Types

- Event created
- Event changed
- Attendance reminder
- Qualification awarded
- Promotion posted
- Transfer completed
- Campaign published
- CONOP published
- AAR requested

## Delivery Channels

- Portal notification
- Discord direct message
- Discord channel message
- Email later if needed

## Rule

Notifications should be targeted and useful. Avoid spam.

New workflows should request delivery through the unified communication pipeline rather than sending directly to Discord.
