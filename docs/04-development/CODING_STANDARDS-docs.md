# Coding Standards

## General

- Keep business logic out of UI components
- Use service functions for domain logic
- Use clear naming
- Prefer explicit permissions
- Validate all user input
- Avoid unnecessary dependencies

## TypeScript

- Use strict mode
- Prefer typed service responses
- Avoid `any`
- Use shared types where useful

## React

- Keep components small
- Separate data fetching from display components where practical
- Use reusable table and form components

## Backend

- Validate input
- Check permissions
- Call services
- Record audit logs
- Return consistent errors
