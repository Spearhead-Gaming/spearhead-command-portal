# Patrol AAR Review UX

## Review Priorities

Review should center:

- Map screenshot state
- Patrol summary
- Tasking
- Callsigns
- Casualties
- Report
- Progression recommendations

## Reviewer Outcomes

The review should support:

- Progression notes
- Recommended next operation version
- Enemy activity
- Friendly activity
- Unit performance notes
- Tasking adjustments
- Clarification requests where supported

Phase 3 Epic 3 surfaces AAR follow-up as a Patrol/S3 next action. A full AAR review layout remains a later workflow polish item.
