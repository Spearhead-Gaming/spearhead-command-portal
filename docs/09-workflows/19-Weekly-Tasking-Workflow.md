# Weekly Tasking Workflow

Weekly Tasking is a first-class Operations object attached to a weekly operation event.

## Doctrine

- Deployments are multi-week operations.
- Each deployment week should have an operation event.
- Weekly Tasking belongs to the operation event, not Discord.
- Every active community unit participates in every deployment.
- Do not select participating units for a deployment.
- Replace "Participating Units" with "Unit Tasking".

## Weekly Tasking Fields

- Week Number
- Operational Summary
- Commander's Intent
- Friendly Situation
- Enemy Situation
- Intelligence Summary
- Logistics Notes
- Weather, optional
- Special Instructions
- Timeline
- Publish / Send Status

## Unit Tasking

Each operational week must contain tasking for every active community unit.

Unit Tasking includes:

- Primary Objective
- Secondary Objective
- Special Equipment
- Special Instructions
- Supporting Assets
- Optional Attachments
- Unit Notes

## Publishing

When an operation event is published or sent to Discord, the attached Weekly Tasking should publish with it.

Discord announcements should present:

1. Operation Information
2. Community Brief
3. Weekly Tasking
4. Unit Taskings
5. Timeline
6. Attendance / RSVP

The portal remains the authoritative source of tasking.
