# Member Profile Workflow

## Purpose

The member profile is the official service record for a Spearhead member.

## Display Name

Use the shared member display-name helper everywhere:

1. Discord display or global name
2. Profile display name
3. Discord username
4. Email
5. Unknown Member

First name and last name are optional and must not be required for workflows.

## Rank

Rank remains available for historical or future use, but it is optional and de-emphasized. Unit, position, status, qualifications, attendance, and readiness are the primary roster context.

## Primary Profile View

- Discord avatar and display name
- Status
- Unit
- Position or billet
- Readiness state
- Attendance summary
- Qualification summary
- Next required action

## Detail Sections

- Assignments
- Qualifications
- Attendance
- Readiness
- Activity
- Notes, restricted
- Community Management, restricted
- Audit, restricted

## Audit

Audit profile creates, profile updates, status changes, unit changes, position changes, qualification changes, and sensitive notes according to the audit logging policy.
