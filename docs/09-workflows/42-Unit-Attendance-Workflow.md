# Unit Attendance Workflow

## Purpose

Attendance is interpreted in unit context. Community-level attendance is aggregate reporting only.

## Unit Policy

Each unit may define:

- Lookback window
- Minimum attendance percentage
- LOA exclusion guidance
- Review notes

## Rules

- Approved LOA should not count as unexcused absence.
- Patrol interest is not attendance.
- Final attendance records should drive readiness, not RSVP alone.
- Do not hardcode one attendance threshold for every unit.

## Permissions

- `attendance.view`
- `attendance.manage`
- `attendance.reports.view`
- `attendance.policies.manage`
