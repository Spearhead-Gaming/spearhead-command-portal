# Next Week Handoff

## Purpose

Next-week planning should begin from reviewed evidence instead of forcing staff to re-enter prior-week context.

## Handoff Summary

The handoff summary should show:

- Intent result
- Progression signal
- Next planning step
- Carry-forward recommendations
- New risks

## Rules

- Do not copy historical artifacts blindly.
- Clearly label inherited or copied content.
- Preserve prior-week history.
- Keep the current week package recoverable after handoff.

Phase 3 Epic 3 adds the initial package handoff summary. Full automatic carry-forward remains future work.
