# Patrol Lifecycle UX

## Simplified Flow

1. Start Patrol.
2. Manage interested members separately from confirmed participants.
3. Complete Patrol.
4. Submit Patrol AAR.
5. Upload required map screenshot.
6. Review AAR.

## UX Rules

- Starting a Patrol should remain possible in under 30 seconds.
- Patrols are lightweight and can run concurrently.
- Patrols are not Weekend Operations.
- Interested members are not final attendance.
- Completing a Patrol should immediately point to AAR submission.
- Discord Scheduled Events are optional for planned Patrols and should not slow ad hoc Patrol start.
- Discord event interest, Patrol interest, confirmed participation, voice presence, and finalized attendance remain distinct.

Phase 3 Epic 3 adds Patrol context, Needs Attention, and next-action treatment to the Patrol page.
