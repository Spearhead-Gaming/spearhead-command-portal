# Deployment Progression UX

## Inputs

- Reviewed Patrol AARs
- Current week's Commander's Intent
- Existing recommendations
- Operational Health
- Staff notes

## Outputs

- Selected next operation version
- Progression decision
- Enemy progression
- Friendly progression
- Planning notes
- Tasking adjustments
- Resource adjustments
- Next-week risks

## Current Epic 3 Decision

The Operations Package now includes a handoff summary that surfaces current intent state, progression signal, and next planning action. It does not create new progression data fields.
