# Deployment Creation Workflow

## Simplified Path

1. Create Deployment.
2. Review Deployment Setup Checklist.
3. Add optional core resources when available.
4. Open Week 1 Operations Package.
5. Schedule the first Weekend Operation.

## Setup Checklist

The checklist is calculated from existing data:

- Deployment created
- Duration configured
- Operational weeks generated
- Zeus configured
- Core resources added
- Week 1 package opened
- Weekend Operation scheduled

Optional resources remain visibly optional. Missing operational weeks or the first Weekend Operation are treated as blockers because they prevent package planning from being actionable.
