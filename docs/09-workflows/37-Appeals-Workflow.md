# Appeals Workflow

## Purpose

Appeals preserve the original case and decision while creating a separate appeal case for review.

## Flow

1. Appellant submits appeal reason and requested remedy.
2. Portal creates an appeal case.
3. Original case is marked appealed.
4. Appeal reviewers review evidence and context.
5. Decision is recorded.
6. Original records remain intact even if the outcome is changed.

Appeal reviewers should not be the same person as the original decision-maker where practical.
