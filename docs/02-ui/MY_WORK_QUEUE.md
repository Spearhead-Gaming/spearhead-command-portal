# My Work Queue

My Work is a persona-aware aggregation of actionable items already known to the Portal.

It is not a separate task-management database.

## Current Sources

- Upcoming personal operation.
- Missing required qualifications.
- Patrol AAR review queue.
- CONOP review queue.
- Pending forms and submissions.
- Unlinked identity/profile issues.
- Failed notification deliveries.
- Missing RSVP or attendance closeout.

## Rules

- Items link to existing domain routes.
- Critical cross-domain alerts can appear outside the selected workspace.
- Items are filtered by workspace relevance.
- No audit entries are created for reading My Work.

## Future Sources

Future epics may add recommendation assignments, case assignments, package approvals, and richer operations release tasks through their owning services.
