# Card Content Standards

Cards should be summary-first.

## Default Card Shape

A default card should contain:

- Title
- One key value or status
- One short supporting line
- One primary action when applicable

## Avoid

- Long metadata stacks
- Multiple equal-weight badges
- Several competing actions
- Repeated page descriptions
- Full histories
- Raw technical details

## Use Instead

- `SummaryCard` for compact metric summaries.
- `NeedsAttention` for actionable problems.
- `CollapsibleSection` for supporting analytics, diagnostics, and history.
- Inspector drawers or detail pages for full records.
