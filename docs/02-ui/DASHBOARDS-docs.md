# Dashboard Designs

## Member Dashboard

Purpose: tell the member what they need to know and do.

Widgets:
- Current unit
- Rank and position
- Next operation
- Current campaign
- Attendance summary
- Required qualifications
- Recent announcements
- Quick links

## Unit Dashboard

Purpose: give leadership a fast unit health view.

Widgets:
- Unit strength
- Active / LOA / inactive counts
- Open billets
- Qualification readiness
- Upcoming operations
- Attendance issues
- Recent changes

## S3 Dashboard

Purpose: mission planning and operations oversight.

Widgets:
- Active campaigns
- Upcoming missions
- Draft missions
- CONOPs awaiting review
- AARs awaiting review
- Mission maker assignments

## Admin Dashboard

Purpose: system oversight.

Widgets:
- Discord connection status
- Pending actions
- Recent audit logs
- Failed notifications
- System health
