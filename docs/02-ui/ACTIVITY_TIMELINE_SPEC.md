# Activity Timeline Specification

## Purpose

The activity timeline provides a human-readable history for members, units, campaigns, events, and system records.

It is different from raw audit logs.

Audit logs are administrative evidence.  
Activity timelines are user-facing history.

## Timeline Entry Anatomy

- icon
- title
- short description
- actor
- timestamp
- related object link
- expandable details

## Member Timeline Events

- Joined Spearhead
- Assigned to unit
- Rank changed
- Position changed
- Qualification awarded
- Qualification revoked
- Attended event
- Missed event
- Campaign participation
- Award received
- Transfer completed
- Status changed

## Unit Timeline Events

- Member assigned
- Member transferred out
- Leadership changed
- Operation completed
- Qualification readiness changed
- Announcement posted

## Campaign Timeline Events

- Campaign created
- Phase changed
- Event added
- CONOP published
- Attendance finalized
- AAR submitted
- Campaign completed

## Event Timeline Events

- Event created
- Event published
- RSVP opened
- Reminder sent
- Attendance recorded
- Attendance locked
- AAR requested

## Display Rules

- Show most recent first in compact feeds.
- Show chronological order in service timelines if appropriate.
- Allow filtering by entry type.
- Allow expansion for details.
