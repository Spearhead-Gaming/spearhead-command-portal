# UI Design System

## Visual Direction

Clean, tactical, modern, readable.

The system should feel professional without becoming visually overwhelming.

## UI Principles

- Clear cards
- Strong hierarchy
- Minimal clutter
- Fast tables
- Search-first workflows
- Responsive layout
- Status badges
- Consistent action placement

## Suggested Palette

- Background: deep charcoal / navy
- Surface: dark slate
- Primary: muted blue
- Accent: amber
- Success: green
- Warning: yellow/amber
- Danger: red
- Muted text: gray-blue

## Components

- Dashboard cards
- Data tables
- Member profile cards
- Status badges
- Qualification chips
- Timeline components
- Campaign progress cards
- Event cards
- Modal forms
- Command palette
