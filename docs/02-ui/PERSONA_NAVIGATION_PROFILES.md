# Persona Navigation Profiles

Navigation remains permission-aware first.

Persona navigation profiles add emphasis by reordering permitted groups and items for the selected workspace.

## Rules

- Never reveal unauthorized routes.
- Never authorize from workspace or persona selection.
- Preferred workspaces may move a group higher in the sidebar.
- Direct links remain valid when route guards allow them.
- Developer tools stay isolated behind explicit permissions.

## Current Groups

- Home
- Operations
- Personnel
- Training
- Communications
- Documents
- Community Management
- Administration
- Developer Tools

## Future Enhancements

Future work may add collapsed navigation preferences per user, but those preferences must never expose unauthorized routes.
