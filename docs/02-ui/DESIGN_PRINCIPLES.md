# Design Principles

## Vision
The portal should feel like a modern Command Information Center—not an administrative website.

## Core Principles
1. Context over navigation.
2. One click to inspect.
3. One click to act.
4. Everything is searchable.
5. Dashboards answer operational questions.
6. Discord complements the portal; the portal is the source of truth.

## Preferred Interaction Order
1. Inline editing
2. Expandable sections
3. Inspector drawers
4. Small modals
5. Full-page workspaces
