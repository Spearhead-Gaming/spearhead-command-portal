# Status and Badge System

## Purpose

Statuses must be readable, consistent, and meaningful.

Badges should communicate state quickly without relying on color alone.

## Semantic Colors

- Success: active, present, qualified, sent
- Warning: pending, maybe, expiring, draft
- Danger: absent, failed, revoked, error
- Info: published, active campaign, assigned
- Muted: archived, inactive, retired

## Badge Rules

- Always include text.
- Use icons sparingly.
- Keep badge labels short.
- Use tooltips for details.
- Use the same status color everywhere.
