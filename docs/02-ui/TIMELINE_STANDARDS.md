# Timeline Standards

Timelines summarize meaningful sequence, not every raw audit event.

## Canonical Timeline Types

- Operational timeline
- Personnel timeline
- Case timeline
- Delivery attempt timeline
- Release history
- Assignment history

## Timeline Item Structure

- Timestamp.
- Event title.
- Actor when available.
- Concise summary.
- Related entity.
- Optional direct action.

## Rules

- Group by date where helpful.
- Keep technical audit detail out of normal timelines.
- Avoid duplicate events from activity and audit sources.
- Keep mobile rows readable.
