# Unit Dashboard Final UX

Unit Dashboard prioritizes current unit health.

## Default View

- Unit context.
- Unit next action.
- Strength.
- LOA and inactive signals.
- Open billets.
- Roster preview.
- Qualification readiness.
- Attendance summary.

## Secondary View

Deployment participation, full billet detail, full roster history, full attendance history, policy configuration, and activity history should be collapsible or inspector-based.

Data must remain unit-scoped. Multi-unit leadership should switch context explicitly.
