# Member Profile Final UX

Member Profile is a service-record overview, not a data dump.

## Default View

- Discord avatar/display name.
- Status.
- Unit.
- Position/Billet.
- Readiness.
- Next required action.
- Current assignment.
- Recent activity.

## Secondary View

Use tabs, inspectors, and collapsible sections for assignments, qualifications, attendance, campaign participation, documents, notes, community management context, service timeline, and audit logs.

Rank is optional and secondary. Technical Discord fields are admin/support metadata, not the visible identity.
