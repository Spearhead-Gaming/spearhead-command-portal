# Accessibility UI Standards

Accessibility is part of operational reliability.

## Baseline Requirements

- Semantic headings and landmarks.
- Visible focus states.
- Keyboard reachable controls.
- Accessible names for icon buttons.
- Status not color-only.
- Error text associated with affected fields where practical.
- Dialog and drawer focus containment.
- Table semantics preserved.
- Upload controls accessible through keyboard.
- Sufficient contrast against dark surfaces.
- Reduced motion respected for new animation.
- Async action feedback announced or visible.
- Focus restored after closing overlays.

## High-Impact Checks

Validate:

- App shell navigation.
- Command palette.
- Inspector drawers.
- Modals and confirmations.
- Dense tables.
- Upload controls.
- Empty/error states.
- Mobile navigation.
