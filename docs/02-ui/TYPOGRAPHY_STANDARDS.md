# Typography Standards

Typography should create hierarchy without making operational pages feel loud.

## Canonical Styles

| Role | Standard |
| --- | --- |
| Page title | `PageHeader` title |
| Section title | `SectionHeader` or card title, `text-lg font-semibold tracking-tight` |
| Card title | `CardTitle` |
| Body | `text-sm text-foreground` |
| Secondary body | `text-sm text-muted-foreground` |
| Metadata | `text-xs font-medium uppercase tracking-[0.14em] text-muted-foreground` |
| Table header | Shared table header styling |
| Error/help text | Concise, actionable, visible near the affected control |

## Rules

- Do not use heading levels only for size.
- Labels should be visible; placeholders do not replace labels.
- Metadata should stay secondary and should not compete with titles.
- Status should not be communicated through typography or color alone.
- Long descriptions should move to collapsible detail, drawer tabs, or inspector panels.
