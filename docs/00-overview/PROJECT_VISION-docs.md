# Project Vision

## Mission Statement

Create a Discord-first command platform that feels invisible to Spearhead members, indispensable to Spearhead leadership, and effortless to expand as the community grows.

## Product Identity

The Spearhead Command Portal is not just a website. It is the operational hub for Spearhead Gaming.

It provides a clean web dashboard for members and leadership while using Discord as the primary everyday interface.

## Core Philosophy

> Purpose-built for Spearhead Gaming, architected for long-term evolution.

The system is built for Spearhead's real workflows, not for every possible Milsim community. However, it should avoid hard-coded assumptions that would make future Spearhead changes difficult.

## Spearhead Initial Structure

Initial unit structure:

- Spearhead Command — Spearhead
- 3rd Infantry Division — Reaper
- 75th Ranger Regiment — Misfit
- 1st Air Cavalry Brigade — Gambler
- Detachment-7 — Viking

These should be stored as configurable seed data, not hard-coded application logic.

## Primary Problems Solved

- Scattered information across Discord, spreadsheets, documents, and forums
- Manual roster updates
- Manual qualification tracking
- Repeated attendance work
- Hard-to-find CONOPs and campaign information
- Poor adoption of external community systems
- Too many steps for members and staff
- Lack of one authoritative source for personnel and operational data

## Product Goals

- Centralize Spearhead rosters
- Track qualifications clearly
- Support campaigns and operations
- Provide useful dashboards
- Reduce duplicate administrative work
- Integrate deeply with Discord
- Remain modular for future Spearhead expansion
