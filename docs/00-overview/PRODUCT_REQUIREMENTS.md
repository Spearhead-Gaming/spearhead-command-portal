# Product Requirements Document

## 1. Overview

The Spearhead Command Portal is a Discord-first personnel, operations, and community management platform for Spearhead Gaming.

## 2. Required MVP Capabilities

### Personnel
- Member profiles
- Roster management
- Rank tracking
- Unit assignment
- Position/billet assignment
- Profile status

### Qualifications
- Qualification catalog
- Member qualification records
- Instructor sign-off
- Qualification matrix
- Unit-required qualifications

### Units
Initial units:
- Spearhead Command
- 3rd Infantry Division (Reaper)
- 75th Ranger Regiment (Misfit)
- 1st Air Cavalry Brigade (Gambler)
- Detachment-7 (Viking)

### Operations
- Events
- Attendance
- RSVP
- Event reminders
- Operation history

### Campaigns
- Campaign overview pages
- Campaign timeline
- Participating units
- Related operations
- CONOP links
- AAR links

### Discord
- Discord OAuth
- Bot notifications
- Channel mapping
- RSVP buttons
- Role sync later

## 3. Non-Goals

- Do not replace Discord
- Do not force members to use the portal for every action
- Do not overbuild ERP-style features in the MVP
- Do not hard-code the current unit structure

## 4. Success Metrics

- Leaders can update roster data quickly
- Qualification status is clear at a glance
- Members can RSVP from Discord
- Campaign pages are easy to read
- Discord remains the primary member workflow
- New modules can be added without redesigning the app
