# ADR-001: Discord-First Architecture

## Status

Accepted

## Context

Spearhead Gaming members have had negative experiences with tools that require extra steps outside Discord.

## Decision

The portal will be Discord-first.

Discord remains the primary user interaction point for routine actions.

The portal remains the authoritative system of record.

## Consequences

- Discord integration is a core feature, not an add-on
- Notifications must be designed carefully
- Many workflows should support Discord buttons or commands
