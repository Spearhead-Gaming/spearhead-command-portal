# ADR-008: MVP Screen-First UI Foundation

## Status

Accepted

## Context

The project needs a stable UI structure before business logic is implemented.

## Decision

The first implementation should create the complete MVP route and screen shell using placeholder data before building full feature logic.

## Consequences

- Navigation and layout can be validated early.
- Codex can build later features into stable page locations.
- UI consistency is established before complex workflows.
- Placeholder data must not become hard-coded business logic.
