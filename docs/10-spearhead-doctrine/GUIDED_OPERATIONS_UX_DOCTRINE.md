# Guided Operations UX Doctrine

Guided Operations UX does not change Spearhead operations doctrine.

The portal may show:

- next recommended action
- current operational week context
- setup checklist
- package journey state
- readiness blockers
- publication status
- patrol and AAR follow-up
- next-week handoff context

The portal must not:

- make autonomous command decisions
- treat Discord as the source of truth
- overwrite release history
- merge Patrols with Weekend Operations
- require Patrol AARs for Weekend Operations
- store duplicate checklist state when completion can be calculated

Guidance is advisory and contextual. Services, permissions, readiness rules, release history, and audit logging remain authoritative.
