# MVP Roadmap

## MVP Goal

Deliver a useful Spearhead portal focused on rosters, qualifications, events, attendance, dashboards, and Discord integration.

## MVP Features

- Discord login
- Member profiles
- Spearhead unit seed data
- Roster management
- Rank tracking
- Position tracking
- Qualifications
- Qualification matrix
- Events
- Attendance
- Member dashboard
- Unit dashboard
- Basic admin dashboard
- Discord event notifications
- Discord RSVP buttons

## MVP Exclusions

- Full RASP workflow
- Advanced ORBAT builder
- Complex automation engine
- Public API clients
- Full S2/S4 tools
- Generic multi-community support

## MVP Success

The MVP is successful if Spearhead leadership can stop relying on spreadsheets for basic roster, qualification, and attendance tracking.
