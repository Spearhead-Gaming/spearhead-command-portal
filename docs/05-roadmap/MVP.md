# MVP Roadmap

## MVP Goal

Deliver a useful portal focused on rosters, qualifications, events, attendance, dashboards, and Discord integration.

## MVP Features

- Discord login
- Member profiles
- Units
- Roster management
- Rank tracking
- Position tracking
- Qualifications
- Qualification matrix
- Events
- Attendance
- Member dashboard
- Unit dashboard
- Basic admin dashboard
- Discord event notifications
- Discord RSVP buttons

## MVP Exclusions

- Full RASP workflow
- Advanced ORBAT builder
- Complex automation engine
- Public API clients
- Full S2/S4 tools
