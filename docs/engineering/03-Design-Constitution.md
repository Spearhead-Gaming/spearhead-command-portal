# Design Constitution

## Non-Negotiable Rules

- Context over navigation.
- Components before pages.
- Discord is a client, not the database.
- Everything searchable.
- One click to inspect.
- One click to act.
- Dashboards answer operational questions.
- Build for expansion, not shortcuts.

## Product Personality

Always:
- Calm
- Professional
- Tactical
- Consistent
- Predictable

Never:
- Cluttered
- Flashy
- Forum-like
- Overly militarized
