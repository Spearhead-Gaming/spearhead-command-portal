# Discord Platform Rollout

## Recommended Sequence

1. Deploy Phase 4 with automatic Discord features disabled.
2. Verify OAuth, REST, and interaction endpoint.
3. Register commands in a test guild.
4. Certify the test guild.
5. Enable Gateway in the test guild if observation features are needed.
6. Run discovery and reconciliation.
7. Enable communications.
8. Validate role automation in Preview Only.
9. Validate scheduled events in Preview.
10. Validate moderation with safe test accounts.
11. Validate application integration.
12. Certify the Primary Community Guild.
13. Add Unit guilds gradually.

Do not enable all guilds and automations simultaneously.
