# Discord Application Review Messages

Review messages notify staff that a Portal application needs attention.

## Routing

Messages route through the Multi-Guild Communication Platform using configured Discord channel mappings. The default mapping for current review alerts is `staff-alerts`.

## Message Content

Review messages may show:

- applicant display label
- application type
- status
- concise summary
- Portal link
- safe reviewer actions

Review messages must not expose sensitive application answers or confidential staff notes.
