# Discord Resource Ownership Rules

Discord resource ownership rules prevent accidental drift from becoming portal truth.

## Portal Owns

- Operational meaning
- Channel mapping purpose
- Role mapping purpose
- Permissions
- Business workflows
- Personnel and member state
- Qualifications
- Attendance
- Deployments and operations

## Discord Owns

- Native resource existence
- Discord resource IDs
- Native resource display metadata
- Permission overwrite metadata
- Native scheduled event metadata
- Emoji and sticker inventory

## Reconciliation Rule

When Discord changes, the Portal observes and records. It does not infer administrator intent.

Administrators must explicitly reconcile missing mapped resources, remaps, disabled mappings, and automation-impacting drift.
