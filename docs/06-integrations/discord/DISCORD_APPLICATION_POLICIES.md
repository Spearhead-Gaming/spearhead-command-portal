# Discord Application Policies

Each managed guild may have a Discord application policy.

## Policy Controls

- application integration enabled
- visible application types
- application entry channel
- review channel
- staff notification channel
- panel enabled
- command availability
- reviewer quick actions enabled
- Portal-only review mode
- applicant status commands enabled
- result notification behavior
- routing priority
- testing mode

Policy controls visibility and routing only. Authorization still uses Portal permission keys.
