# Communication Domains

## Domain Principle

Every communication belongs to exactly one domain. Domains describe why the message exists, not where it should go.

## Initial Domains

- Operational Releases
- Weekend Operations
- Patrols
- Training
- Applications
- Recruitment
- Personnel
- Qualifications
- Attendance
- Community
- Moderation
- Administration
- Developer
- Health
- Diagnostics
- Announcements
- Alerts
- Emergency

## Default Mapping Keys

Each domain has a default Discord mapping key used when a guild does not override the domain in configuration.

Examples:

- `operational_releases` -> `campaign-updates`
- `weekend_operations` -> `events`
- `patrols` -> `patrols`
- `applications` -> `staff-alerts`
- `moderation` -> `staff-alerts`
- `health` -> `admin-alerts`

These are defaults, not hardcoded feature decisions.
