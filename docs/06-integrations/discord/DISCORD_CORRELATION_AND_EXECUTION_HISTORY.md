# Discord Correlation and Execution History

## Purpose

Correlation links Portal events, Discord delivery, REST actions, Gateway observations, reconciliation, and audit history.

## Search Keys

- correlation ID
- interaction ID

- Discord user ID

## Timeline Stages

Portal Event -> Validation -> Planning -> Approval -> Queue -> REST Execution -> Gateway Observation -> Communication Delivery -> Reconciliation -> Completed.

Do not include raw secrets, request headers, bot tokens, OAuth tokens, or signed continuation tokens.
