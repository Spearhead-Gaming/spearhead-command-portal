# Discord Warnings

Warnings are Portal-owned moderation records. Discord has no native warning API.

## Rules

- Warning requires `discord.moderation.warn`.
- Warning creates or attaches to a `CommunityCase`.
- Warning creates a case decision and appears in moderation history.
- Optional communication should flow through the Unified Communication Platform.

Warnings are appropriate for behavior that needs durable history but does not require immediate Discord enforcement.
