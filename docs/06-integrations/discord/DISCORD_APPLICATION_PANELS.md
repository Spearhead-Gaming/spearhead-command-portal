# Discord Application Panels

Application panels are optional persistent Discord messages that can point members toward Portal-owned application workflows.

Phase 4 Epic 9 prepares catalog and policy data for panels but does not automatically publish live panels.

## Panel Rules

- Generated by the Portal.
- No duplicate panel spam.
- Buttons point to Portal continuation or command flows.
- Deleted panels should be recreated only by explicit staff action.
- Panel versioning and full lifecycle management are deferred until Phase 5.
