# Discord Application Catalog

The Discord Application Catalog describes how Discord exposes Portal workflows. It is not the application definition and does not store applicant answers.

## Catalog Fields

- application type key
- display name
- description
- availability
- eligibility summary
- applicant scope
- owning domain
- Portal route
- Discord start behavior
- review destination
- communication domain
- Phase 5 provider key
- enabled and maintenance state

## Current Entries

- Recruit Application: enabled when a Portal recruit form template is enabled.
- RASP Application: enabled when a Portal RASP form template is enabled.
- Unit Transfer Application: enabled when a Portal transfer form template is enabled.

Future entries remain disabled or unavailable until Phase 5 providers exist.
