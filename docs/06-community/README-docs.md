# Spearhead Operations Documentation

This folder documents Spearhead-specific workflows.

These documents define how Spearhead should operate inside the portal before implementation begins.

## Workflow Documentation Standard

Each workflow should define:

1. Purpose
2. Current process analysis
3. Pain points
4. Desired portal workflow
5. Required portal features
6. Discord integration
7. Required data
8. Permissions
9. Automation opportunities
10. Audit requirements
11. Dashboard integration
12. Future expansion

## Planning Rule

Document the workflow before building the feature.
