# Workflow Documentation Template

Use this template for every major Spearhead workflow.

## Workflow Name

Example: Qualification Awarding

## Current Workflow

Describe how Spearhead handles this today.

## Pain Points

Describe what is slow, confusing, duplicated, or error-prone.

## Desired Portal Workflow

Describe the ideal future process.

## Portal Features Required

List required screens, forms, actions, and views.

## Discord Integration

Define what happens in Discord:
- commands
- buttons
- notifications
- channel posts
- role sync

## Required Data

List the records and fields needed.

## Permissions

Define who can view, create, approve, edit, or delete.

## Automation Opportunities

List what should happen automatically.

## Audit Requirements

List what actions must be logged.
