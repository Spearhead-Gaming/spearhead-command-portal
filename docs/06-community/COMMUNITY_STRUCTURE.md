# Spearhead Community Structure

## Purpose

Define the initial Spearhead organization structure used by the portal.

## Initial Units

### Spearhead Command
Callsign: Spearhead

Role:
- Community command
- Strategic oversight
- Cross-unit coordination
- Final administrative authority where required

### 3rd Infantry Division
Callsign: Reaper

Role:
- Infantry unit
- Primary line unit structure
- General operations participation

### 75th Ranger Regiment
Callsign: Misfit

Role:
- Ranger-focused unit
- May require selection or RASP-style workflow
- May have additional qualification or attendance requirements

### 1st Air Cavalry Brigade
Callsign: Gambler

Role:
- Aviation-focused unit
- Pilot/crew qualifications
- Air mission support

### Detachment-7
Callsign: Viking

Role:
- Specialized detachment
- May require restricted access, qualification rules, or special assignment workflows

## Architecture Rule

These units must be stored as records in the database and seeded during setup.

Application code should not depend on hard-coded unit names.
