# Phase 4 Discord Guild Certification

Guild certification is technical readiness only. It does not grant permissions.

## Certification States

- Not Evaluated
- Ready
- Ready with Warnings
- Not Ready
- Disabled
- Expired

## Capabilities

- Member Sync
- Communications
- Role Automation
- Scheduled Events
- Moderation
- Applications
- Voice Awareness
- Attachment Continuation

## Minimum Ready Criteria

- guild is active
- exactly one Primary Community Guild exists across the platform
- discovery is current
- required resources are mapped by ID
- bot permissions are verified
- feature policy is enabled where applicable
- no unresolved critical reconciliation issues

Use the Operations Center readiness panel and `npm run discord:platform:preflight` for current local evidence.
