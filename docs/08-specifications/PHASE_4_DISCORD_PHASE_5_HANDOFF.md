# Phase 4 Discord Phase 5 Handoff

## Phase 4 Provides

- multi-guild records and discovery
- explicit mappings
- interaction webhook and command catalog
- Gateway observation layer
- communication routing
- role automation foundation
- scheduled event management foundation
- moderation platform foundation
- application catalog and continuation links
- readiness, diagnostics, and certification summaries

## Deferred to Phase 5

- complete Application Engine
- visual Form Builder
- generic provider registry
- approval workflow designer
- application panel lifecycle editor
- advanced analytics
- generalized automation builder

## Handoff Rule

Phase 5 should build on the Phase 4 contracts instead of replacing Discord handlers with application-specific one-offs.
